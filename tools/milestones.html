"Every" is the spacing of the marks. "Loud one" lifts every n-th mark to the big version — so the first million does not look like the next hundred thousand. Records instead use a floor, so a weapon you just picked up does not celebrate its first hit.

Queue puts a test milestone into the same queue the poller uses, so a running source picks it up within one poll cycle — that exercises the whole path including the shown-marker. Open loads the source in a new tab and plays that one occasion straight away, without queueing anything. Both use the mark that would really fall next.
