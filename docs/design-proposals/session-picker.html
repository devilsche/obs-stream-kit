Session picker — three sketches

The range and session controls in the session report, redrawn with the real 89 sessions in the database (1 134 matches, 81 chicken dinners). Every sketch is clickable. Today the report has two tabs plus month accordions; all three sketches replace that with one bar built from the same switch element that shot-quality and landing-spots already use.

A · One bar, like the other tools

The range switch is the same element as in the other tools, so it reads the same way. Underneath, one line for the session with arrows to the neighbours — stepping to the session before is the most common move and costs one click instead of opening a month and scrolling.

Gone: the two tabs, the month accordions, the sort dropdown. Kept: every preset, now as switch buttons. Trade-off: the list still needs scrolling for older sessions.

B · Sessions as a timeline

Same bar, but the session picker is a strip of bars — one per session, height by match count. All 89 fit without scrolling, and the gaps are visible as what they are: days you did not play. Arrow keys step through it.

Range

    Extra: playing patterns and breaks are readable at a glance. Trade-off: bars get thin as the record grows — at 500 sessions this needs paging or zoom, and it is the most work to build.

    C · One field with a filter

    Same bar, but the session list carries a filter and month headers as separators instead of accordions — nothing to unfold. Typing beats scrolling once the record spans years.
