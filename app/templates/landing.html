build Tools (in the dashboard)

Session Report

Detailed report per session: matches with squad table, mini map with movement paths, kills/knocks per player, hot drop detection, achievements, bot team counts. Each match expands into a time-lapse replay.

Match Replay

Full match replay with all 100 players, teams, flight path, blue zone, kill/knock markers, shot lines. 1×/2×/4×/ 8×/16× speed. Team focus with zoom. Filter across all stored matches.

Landing Spots

Heatmap of landing spots across all matches — yours and your squad mates, filterable per map.

Achievement Browser

Full-screen browser through all Steam & PUBG achievements. Filter by game, sort by date/rarity/name. Click-to-replay triggers the popup widget for stream recaps.

settings How it works

  1. Log in with Twitch (OAuth) — an admin approves your account.
  2. In the settings, enter your PUBG API key (free, developer.pubg.com) and your Steam API key (steamcommunity.com/dev).
  3. The server polls your PUBG and Steam data every 10 s in the background and fills your database tables.
  4. On /app/urls you get a token URL for every widget that you paste into OBS as a browser source.
  5. Tools live under /app/tools (dashboard, not an OBS browser source).
